GadgetHub E-commerce Frontend
=============================

Files:
- index.html: page structure and Bootstrap layout
- style.css: responsive storefront styling
- app.js: sample products, search, category filters, sorting, wishlist, and localStorage cart

Run:
1. Extract the ZIP.
2. Open index.html in a modern browser, or use VS Code Live Server.
3. Internet connection is needed for Bootstrap CDN, Google Fonts, Bootstrap Icons, and remote Unsplash images.

Important:
- This is a frontend demo. Products are sample data in app.js.
- Cart is saved in the browser's localStorage.
- Checkout, user accounts, payments, stock, and order management need a backend/API.
- Replace sample contact information and product details before publishing.
